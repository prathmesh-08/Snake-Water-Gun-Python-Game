# Snake Water Gun Game

A simple command-line Snake Water Gun game built using Python.

## About the Project

Snake Water Gun is a beginner-friendly Python game similar to Rock Paper Scissors.

The player chooses Snake, Water, or Gun. The computer randomly selects an option, and the program determines the winner.

## Features

- User input for game choices
- Random computer choice
- Automatic winner calculation
- Simple command-line interface

## Technologies Used

- Python
- Random module
- Conditional statements
- Functions
- User input

python main.py
